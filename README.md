# Margitta Bolttérkép

Telefonra készült, nem hivatalos térkép-app a margittai (Marghita, Bihor) Lidl-hez.

- **Térkép:** a bolt alaprajza részlegekkel, kereső (magyarul és románul), útvonal a bejárattól.
- **Lista:** bevásárlólista, ami magától bejárási sorrendbe rendeződik; útvonal a térképen.
- **Bolt:** cím, élő nyitva/zárva jelzés (Europe/Bucharest idő), parkoló, tippek, források.

Az alaprajz a szokásos Lidl-elrendezést követi; ha valami máshol van, a terméknél át lehet helyezni, és az app megjegyzi (localStorage).

Szerkesztés: `src/app.html`, majd `./build.sh` → `index.html`. Telefonon: GitHub Pages-en megnyitva „Hozzáadás a kezdőképernyőhöz”, offline is működik.
